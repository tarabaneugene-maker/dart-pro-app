### 🏃 Спринт 2 — Полный цикл онлайн-матча 501 (1v1)

**Цель:** Два игрока проходят путь вход → лобби → комната → матч → результат без ручных обходов.

#### Критерии приёмки (DoD)

- [ ] Игрок A: вход → «Создать игру» → видит код комнаты
- [ ] Игрок B: вход → «Вступить по коду» → запрос у A → A нажимает «Начать» → оба в игре
- [ ] Ходы синхронизируются; bust/checkout соблюдаются
- [ ] Победа в леге/матче отображается у обоих
- [ ] После матча оба возвращаются в лобби без зависания
- [ ] При обрыве Wi‑Fi на 5–10 с и восстановлении матч продолжается или корректный forfeit

### Что изменилось в этом обновлении
- **Авто-вход по токену** — если игрок поставил галочку «Запомнить меня», при нажатии на вкладку «Онлайн» подключение происходит автоматически, без повторного ввода логина/пароля
- **Авто-обновление лобби** — `_broadcastLobbyUpdate()` вызывается на сервере при создании комнаты, принятии/отклонении запроса, выходе создателя, отключении игрока, начале игры. Клиент обновляет список комнат через `LobbyUpdateEvent` без ручного перезахода
- **Улучшенный UX комнаты** — после нажатия «Присоединиться» кнопка меняется на «Ожидание игры...» с индикатором. При отказе — AlertDialog с именем создателя. При начале игры без нас — AlertDialog «Игра уже началась». При ошибке «Комната заполнена» — AlertDialog с возвратом в лобби
- **Деплой на VPS** — полный стек на одном сервере: Flutter Web + Dart сервер + Caddy (HTTPS). Домен: `https://192.144.13.217.nip.io`
  - `deploy_vps.ps1` — PowerShell скрипт для деплоя с локальной машины (SSH + sudo)
  - `server/setup.sh` — bash-скрипт для деплоя с VPS (git pull → docker build → docker run)
  - `Dockerfile` — multi-stage сборка: Flutter Web + Dart сервер в один образ
  - `.github/workflows/deploy.yml` — **НЕ ИСПОЛЬЗУЕТСЯ** (Vercel не нужен, всё на VPS)
